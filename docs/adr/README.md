# ADRs de arquitetura

Decisoes de arquitetura **do produto**, no padrao de nomes de `joujou9/delegate`:
`NNNN-titulo-em-portugues.md`.

Nasce vazio de proposito. Ate aqui todas as decisoes foram de **nivel de fork**
-- relacao com o upstream, layout, formatacao, distribuicao -- e essas vivem em
[`docs/fork/decisions/`](../fork/decisions/), junto do inventario de
customizacoes e do log de sync, como o guia de fork exige.

A separacao existe para que a pergunta "por que este fork e assim?" e a pergunta
"por que o produto e assim?" nao se misturem no mesmo diretorio.
